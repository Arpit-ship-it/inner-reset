❌ TROUBLESHOOTING:

PROBLEM: Users not showing?

   CHECK 1: Both terminals running?
   CHECK 2: Browser console (F12) shows no red errors?
   CHECK 3: Open http://localhost:5000/api/auth/users
            Should show JSON with users

PROBLEM: Database error "Unknown column 'status'"?

   SOLUTION: Restart backend
   1. Press Ctrl+C in Terminal 1
   2. Run: node server.js

PROBLEM: Port 5000 already in use?

   SOLUTION: Find and kill the process
   1. Run: lsof -i :5000
   2. Run: kill -9 <PID>
   3. Run: node server.js
